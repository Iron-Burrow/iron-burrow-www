What Iron Burrow provides

Evidence boundaries for crypto workflows.

Iron Burrow is built for cases where an answer needs to be traceable, reproducible, and useful for compliance review.

It is not positioned as a generic RPC provider or broad data vendor. The current work focuses on deterministic, source-aware evidence that business, compliance, and technical teams can inspect together.
